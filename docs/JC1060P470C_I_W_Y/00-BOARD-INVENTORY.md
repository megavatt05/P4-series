## 2. Ключевые пины (сводка)

### Дисплей (JD9165 MIPI-DSI)
| Функция | GPIO | Примечание |
|---------|------|----------|
| LCD Reset | **5** или **27** | В разных демо встречаются оба — проверять по схеме |
| Backlight (PWM) | **23** | LEDC |
| MIPI-DSI PHY power | LDO channel **3** | 2.5 В, обязательно до init DSI |
| Data lanes | 2-lane | lane_bit_rate обычно 550–1000 Mbps |

### Тач (GT911)
| Функция | GPIO |
|---------|------|
| I2C SDA | **7** |
| I2C SCL | **8** |
| RST | **22** |
| INT | **21** |
| Адрес | 0x5D (или 0x14) |

### Аудио (ES8311)
| Функция | GPIO |
|---------|------|
| I2C (та же шина) | 7 / 8 |
| I2S MCLK | 13 |
| I2S BCLK | 12 |
| I2S WS/LRCK | 10 |
| I2S DOUT | 9 |
| I2S DIN | 48 (или 11) |
| PA / AMP_EN | 11 или 20 |

### Wi-Fi (ESP32-C6 через ESP-Hosted)
| Функция | GPIO |
|---------|------|
| C6 Reset | **54** |
| SDIO CLK | **18** |
| SDIO CMD | **19** |
| SDIO D0–D3 | **14 / 15 / 16 / 17** |

### SD-карта (SDMMC)
| Функция | GPIO |
|---------|------|
| CLK | **43** |
| CMD | **44** |
| D0–D3 | **39 / 40 / 41 / 42** |
| Power | LDO channel **4** |

> ⚠️ **Конфликт**: линии SDIO SD-карты и ESP32-C6 пересекаются по ресурсам контроллера. При активном Wi-Fi SD обычно недоступна.

### Ethernet (IP101)
| Функция | GPIO (типичные) |
|---------|-----------------|
| MDC | 31 |
| MDIO | 52 |
| Power / CLK | 51 / 50 |

### Камера (MIPI-CSI)
| Функция | GPIO |
|---------|------|
| Reset / PWDN | часто NC или отдельные |
| SCCB (I2C) | общая шина 7/8 или отдельная |

## 5. Критические настройки (перед любой сборкой)

1. **Chip revision**: Minimum Supported = **Rev v1.0**, выбирать revisions **< 3.0** (engineering sample).
2. Partition table offset: **0x10000**, первый partition ≥ **0x11000**.
3. Включить PSRAM + при необходимости `CONFIG_SPIRAM_XIP_FROM_PSRAM`.
4. Для логов предпочтительно **USB High-Speed** порт.
5. LDO channel 3 (2.5 В) — **до** инициализации MIPI-DSI.
